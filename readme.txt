Gestor de pop-ups promocionales para NTG Turismo.

== Description ==
Plugin base para administrar pop-ups promocionales desde WordPress.

== Installation ==
1. Subir la carpeta del plugin a `/wp-content/plugins/`.
2. Activar **NTG Turismo Popups** desde el panel de WordPress.
